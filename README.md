# Air Canvas — Hand Gesture Drawing

Draw on a digital canvas using webcam-based hand tracking.

## Features
- Real-time hand tracking and gesture recognition
- Draw using finger gestures
- Select colors and erase content
- Clear the canvas with a hand gesture

## Stack
Python, OpenCV, MediaPipe.

## Setup
Install the dependencies used by the project, then run its main Python script. Check the source files for the actual entry point and any additional requirements.

## Note
Camera access is required. Gesture behavior may depend on lighting and camera quality.
